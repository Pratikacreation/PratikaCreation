PRATIKA CREATION WEBSITE
========================

1. Open index.html in Chrome/Edge to preview the website.
2. Put the client WhatsApp number in:
   Manage Products (lock icon) -> WhatsApp number with country code -> Save Settings.
   Example format: 919876543210
3. The supplied 25 images + 2 videos are already arranged into categories.
4. Manage Products lets you add, edit, replace media, feature, and delete products.
5. No prices are displayed anywhere on the public product cards.
6. Enquire buttons open WhatsApp with the selected product name/category.
7. Product/admin changes are stored in the current browser's localStorage.
8. This is suitable for a static/demo site. For a real multi-device admin panel,
   connect a secure backend/database and cloud media storage.
